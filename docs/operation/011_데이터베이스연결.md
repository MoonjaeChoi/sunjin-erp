### 3.1 현재: Direct oracledb 연결 (`src/lib/db-direct.ts`)

**SELECT 쿼리 실행**

```typescript
import { executeQuery } from '@/lib/db-direct';

export async function GET(request: NextRequest) {
  try {
    const result = await executeQuery(
      `SELECT * FROM EMPLOYEE WHERE "id" = :id`,
      { id: 1 }
    );
    return NextResponse.json(result.rows);
  } catch (error) {
    console.error('Error:', error);
    return NextResponse.json({ error: 'Internal server error' }, { status: 500 });
  }
}
```

**INSERT/UPDATE/DELETE 실행**

```typescript
import { executeUpdate } from '@/lib/db-direct';

export async function POST(request: NextRequest) {
  try {
    const { name, email } = await request.json();

    await executeUpdate(
      `INSERT INTO EMPLOYEE (name, email) VALUES (:name, :email)`,
      { name, email }
    );

    return NextResponse.json({ success: true }, { status: 201 });
  } catch (error) {
    console.error('Error:', error);
    return NextResponse.json({ error: 'Internal server error' }, { status: 500 });
  }
}
```

## 4. Oracle 연결 문제 해결

### 4.1 Connection String 형식

**올바른 형식**
```
192.168.75.194:1521/XEPDB1
```

**문제가 되는 형식**
```
192.168.75.194:1521:XEPDB1  (❌ 콜론 사용)
localhost:1521/XE           (❌ 서비스명 오류)
```

### 4.2 열 식별자 케이싱 규칙

Oracle에서는 **quoted identifier** 사용 시 **대소문자 구분**

| 테이블 | 열 이름 | 예시 |
|--------|---------|------|
| EMPLOYEE | 소문자 | `"id"`, `"username"`, `"password_hash"` |
| CUSTOMER | 소문자 | `"id"`, `"name"`, `"deleted_at"` |
| ISSUE | 대문자 | `"ID"`, `"CUSTOMER_ID"`, `"CREATED_AT"` |

**실패 케이스**
```sql
-- ❌ 에러: ORA-00904
SELECT "id" FROM ISSUE WHERE "CUSTOMER_ID" = 1

-- ✓ 성공
SELECT "ID" FROM ISSUE WHERE "CUSTOMER_ID" = 1
```

### 4.3 JOIN 시 열 식별자 혼용

```typescript
// ✓ 올바른 JOIN 쿼리
const query = `
  SELECT
    "i"."ID",
    "i"."CUSTOMER_ID",
    "c"."name"
  FROM ISSUE "i"
  LEFT JOIN CUSTOMER "c" ON "c"."id" = "i"."CUSTOMER_ID"
`;
```

## 8. 주의사항

1. **Connection String 검증** - 포트와 서비스명 정확히 확인
2. **열 식별자 케이싱** - 각 테이블의 스키마 확인 후 대소문자 맞춰서 사용
3. **QueryRunner 해제** - try/finally에서 반드시 `release()` 호출
4. **타임아웃** - 네트워크가 느린 경우 타임아웃 값 증가
5. **환경 변수** - `.env` 파일이 git에 커밋되지 않도록 주의
