### GET /api/maintenance/stats - 계약 통계

**권한**: USER+

**응답**:
```json
{
  "byStatus": {
    "활성": 10,
    "종료": 5,
    "갱신예정": 3
  },

  "expiringIn60Days": 5

```

**계산**:

- expiringIn30Days: 30일 내 만료 계약
- expiringIn60Days: 60일 내 만료 계약
