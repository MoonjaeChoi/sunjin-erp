### 구현 상세

#### 1. POST /api/projects - 프로젝트 등록

**인증**: NextAuth session 필수 (미인증 시 401)

**RBAC**: 모든 인증된 사용자(ADMIN/MANAGER/USER) 등록 가능

**Request Body:**
```json
{
  "project_name": "삼성전자 네트워크 구축",
  "customer_id": 1,
  "employee_id": 3,
  "project_code": "PJT-20260125-001",
  "start_date": "2026-01-01",
  "end_date": "2026-06-30",
  "contract_amount": 50000000,
  "description": "프로젝트 설명"
}
```

**필수 필드:**
- `project_name` (string, 1~200자)
- `customer_id` (number, CUSTOMER 테이블에 존재해야 함)
- `employee_id` (number, EMPLOYEE 테이블에 존재해야 함)

**선택 필드:**
- `project_code` (string, 최대 30자, 제공 시 UNIQUE 검증)
- `start_date` (string, YYYY-MM-DD)
- `end_date` (string, YYYY-MM-DD)
- `contract_amount` (number, 0 이상)
- `description` (string)

**검증 규칙:**
1. `project_name`: 필수, 1~200자
2. `customer_id`: 필수, CUSTOMER 테이블에 존재 (deleted_at IS NULL)
3. `employee_id`: 필수, EMPLOYEE 테이블에 존재 (deleted_at IS NULL)
4. `project_code`: 제공 시 UNIQUE 검증 (기존 project_code와 중복 불가)
5. 날짜 순서: `start_date`와 `end_date` 모두 제공 시 `start_date <= end_date`
6. `contract_amount`: 제공 시 0 이상

**처리 로직:**
1. Session 확인
2. Request body 파싱 및 검증
3. FK 존재 확인 (customer_id, employee_id)
4. project_code 중복 확인 (제공 시)
5. PROJECT 테이블에 INSERT (status = 'PREPARING')
6. 생성된 id 반환

**응답:**
- 201 Created: `{ id: number }`
- 400 Bad Request: `{ error: string, details?: Record<string, string> }`
- 401 Unauthorized: `{ error: "Unauthorized" }`
- 409 Conflict: `{ error: "Project code already exists" }` (중복 코드)
- 500 Internal Server Error: `{ error: string }`

#### 2. POST /api/projects/generate-code - 프로젝트 코드 생성

**인증**: NextAuth session 필수 (미인증 시 401)

**코드 생성 규칙:**
- 형식: `PJT-YYYYMMDD-NNN`
- YYYYMMDD: 요청 시점의 날짜 (서버 시간, KST)
- NNN: `PROJECT_CODE_SEQ.NEXTVAL` 값을 3자리로 패딩 (001, 002, ..., 999, 1000, ...)

**처리 로직:**
1. Session 확인
2. Oracle에서 `SELECT PROJECT_CODE_SEQ.NEXTVAL FROM DUAL` 실행
3. 현재 날짜(KST) 포맷팅: YYYYMMDD
4. 코드 조합: `PJT-${yyyymmdd}-${nnn.toString().padStart(3, '0')}`
5. 생성된 코드 반환

**응답:**
- 200 OK: `{ code: string }`
- 401 Unauthorized: `{ error: "Unauthorized" }`
- 500 Internal Server Error: `{ error: string }`

**동시성 안전:**
- Oracle SEQUENCE는 동시 접근 시에도 유일한 값을 보장
- 같은 날 여러 요청이 동시에 와도 NNN이 중복되지 않음
