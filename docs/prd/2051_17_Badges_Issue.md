## 구현 내용

### IssueSummaryBadges.tsx (Client Component)

**표시**
```
전체: 12 | 접수: 5 | 진행중: 4 | 완료: 3
```

**기능**
1. useIssueSummaryQuery로 카운트 조회
2. 필터 변경 시 자동 업데이트 (queryKey 변경)
3. 배지 클릭 → 해당 상태로 필터 추가 (AND 조합)
4. 클릭한 상태 배지는 활성화 표시

**예시**
- "전체" 클릭: status 필터 제거 (모든 상태)
- "진행중" 클릭: status=IN_PROGRESS 필터 추가
- 이미 "진행중" 필터 있으면: 필터 제거
