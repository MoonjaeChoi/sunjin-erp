**이벤트 핸들러:**

```typescript
// 필터 업데이트 (page를 1로 리셋)
const handleFilterUpdate = (params: Partial<ProjectSearchParams>) => {
  setSearchParams((prev) => ({ ...prev, ...params, page: 1 }));
};

// 상태 뱃지 클릭 (상태 필터 토글)
const handleStatusBadgeClick = (status: ProjectStatus) => {
  setSearchParams((prev) => {
    const currentStatuses = prev.status || [];
    const newStatuses = currentStatuses.includes(status)
      ? currentStatuses.filter((s) => s !== status)
      : [status]; // 단일 선택으로 전환 (뱃지 클릭은 단일 필터)
    return { ...prev, status: newStatuses.length > 0 ? newStatuses : undefined, page: 1 };
  });
};

// 테이블 행 클릭 (상세 Dialog 열기)
const handleRowClick = (projectId: number) => {
  setSelectedProjectId(projectId);
  setDetailDialogOpen(true);
};

// 페이지 변경
const handlePageChange = (page: number) => {
  setSearchParams((prev) => ({ ...prev, page }));
};

// 정렬 변경
const handleSortChange = (sort_by: string, sort_order: 'ASC' | 'DESC') => {
  setSearchParams((prev) => ({ ...prev, sort_by, sort_order, page: 1 }));
};
```

#### 3. ProjectSummaryBadges.tsx

```typescript
// src/components/features/projects/ProjectSummaryBadges.tsx
'use client';

import { ProjectSummary, ProjectStatus, ProjectStatusLabel, ProjectStatusColor } from '@/types/project';
import { Badge } from '@/components/ui/badge';

interface ProjectSummaryBadgesProps {
  summary: ProjectSummary | undefined;
  activeStatus: ProjectStatus[] | undefined;
  onStatusClick: (status: ProjectStatus) => void;
}
```

**렌더링:**

```tsx
const statuses: ProjectStatus[] = ['PREPARING', 'IN_PROGRESS', 'COMPLETED', 'ON_HOLD'];

return (
  <div className="flex gap-3">
    {statuses.map((status) => {
      const isActive = activeStatus?.includes(status);
      const count = summary ? summary[statusToKey(status)] : 0;
      const color = ProjectStatusColor[status];

      return (
        <Badge
          key={status}
          variant="outline"
          className={cn(
            'cursor-pointer px-3 py-1.5 text-sm transition-colors',
            color.bg, color.text,
            isActive && 'ring-2 ring-offset-1 ring-current',
          )}
          onClick={() => onStatusClick(status)}
        >
          {ProjectStatusLabel[status]}: {count}
        </Badge>
      );
    })}
  </div>
);

// status → summary key 변환
function statusToKey(status: ProjectStatus): keyof ProjectSummary {
  const map: Record<ProjectStatus, keyof ProjectSummary> = {
    PREPARING: 'preparing',
    IN_PROGRESS: 'in_progress',
    COMPLETED: 'completed',
    ON_HOLD: 'on_hold',
  };
  return map[status];
}
```

**뱃지 동작:**
- 클릭 시 해당 상태로 목록 필터링
- 활성 상태는 ring 스타일로 강조
- 색상: blue(준비), amber(진행중), green(완료), gray(보류)
- summary 데이터 로딩 중에는 count=0 표시
