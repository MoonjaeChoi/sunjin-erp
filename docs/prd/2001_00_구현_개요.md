## 특이사항

이 PRD는 **순수 프론트엔드 레이아웃**으로, Database Layer와 API Layer가 불필요합니다:
- DB 의존성 없음 (메뉴 구성은 정적 코드 상수)
- 커스텀 API Route 없음 (NextAuth 기본 제공 엔드포인트만 사용)
- 사용자 정보(이름, 역할, 부서)는 NextAuth session에서 제공

따라서 구현 순서는: **Configuration → Store → Layout → Components → Testing**
