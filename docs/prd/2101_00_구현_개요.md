## 개요

공지사항 모듈은 조직 내 의사소통을 위한 게시판 시스템을 제공합니다.
- 5가지 게시판 유형 (공지, 공유, 지시, 건의, 자유)
- 2단계 댓글 시스템 (댓글 → 답글)
- 파일 첨부 (매직 바이트 검증)
- 세션 기반 조회수 추적
- Soft Delete Cascade (게시물 삭제 시 댓글/첨부파일 연쇄 삭제)

## 핵심 설계 결정 (PRD v2 반영)

| 결정 | 내용 |
|------|------|
| **Soft Delete Cascade** | Notice 삭제 시 Comment, Attachment 연쇄 soft delete |
| **파일 검증** | 매직 바이트 기반 MIME 타입 검증 (file-type 라이브러리) |
| **댓글 깊이** | 최대 2단계 (댓글 → 답글), HTTP 400 반환 |
| **조회수 중복 제외** | 세션 기반 (동일 세션 = 1회) |
| **검색** | LIKE 기반 (FTS는 Phase 2) |
| **상세 페이지** | ISR (revalidate = 3600초) |
| **댓글 정렬** | oldest-first (시간순) |
