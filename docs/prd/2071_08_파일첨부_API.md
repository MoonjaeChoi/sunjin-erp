# 파일 첨부 관리 API

**문서 번호**: 2071_08
**복잡도**: L (2-3일)

## 엔드포인트들

### POST /api/maintenance/[id]/attachments - 파일 업로드

**권한**: MANAGER+ (MANAGER, ADMIN)

**요청**: multipart/form-data
- file (필수): PDF, DOCX, DOC
- 최대 크기: 10MB
- 최대 5개 파일

**구현**:
- 파일명: UUID + 원본명 (예: uuid-contract.pdf)
- 저장 경로: /uploads/maintenance/
- MIME 타입 검증 (매직 바이트)
- 5개 제한 검증
- 업로더 자동 기록

**응답** (201 Created):
```json
{
  "id": 1,
  "file_name": "contract.pdf",
  "file_size": 102400,
  "created_at": "2026-01-26T21:30:00Z"
}
```

### GET /api/maintenance/[id]/attachments - 파일 목록

**권한**: USER+ (모든 사용자)
**페이지네이션**: 10개/페이지

**응답**:
```json
{
  "data": [{ "id": 1, "file_name": "contract.pdf", ... }],
  "pagination": { "page": 1, "limit": 10, "total": 2 }
}
```

### GET /api/maintenance/[id]/attachments/[attachmentId]/download - 파일 다운로드

**권한**: USER+
**구현**:
- Content-Disposition: attachment (강제 다운로드)
- 파일 존재 검증
- 404 if not found

### DELETE /api/maintenance/[id]/attachments/[attachmentId] - 파일 삭제

**권한**: ADMIN만
**구현**:
- Soft delete (`deleted_at` 설정)
- 404 if not found
