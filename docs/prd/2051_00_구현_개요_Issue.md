## 주요 구현 특성

### RBAC & is_public 필터링
- ADMIN: 모든 Issue 조회/수정/삭제
- MANAGER: 같은 부서, 부서 내 담당자만 할당
- USER: 자신 생성/담당 + 부서 공개, 신규 등록만
- is_public 기본값: false

### 처리 시간 포맷팅
- 입력: 분 단위 (1~1440)
- 표시: "약 2시간 30분" 형식
- 실시간 변환

### 파일 첨부 이중 검증
- 프론트엔드: 즉시 검증
- 서버: 재검증 (보안)
- 제한: 10MB/파일, 5개/장애
- ON DELETE RESTRICT

### 변경 이력 추적
- 상태, 담당자, 심각도 변경
- 파일 업/삭, 롤백
- old_value, new_value, changed_by 기록

### 상태 롤백 (ADMIN만)
- COMPLETED → IN_PROGRESS
- 확인 다이얼로그
- STATUS_ROLLBACK 기록
