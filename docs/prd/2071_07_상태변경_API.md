# 계약 상태 변경 API

**문서 번호**: 2071_07
**복잡도**: M (1-2일)
**의존성**: 2071_05~06

## 엔드포인트

### POST /api/maintenance/[id]/status

**권한**: MANAGER+ (MANAGER, ADMIN)

**요청**:
```json
{
  "status": "종료",
  "reason": "계약 만료"
}
```

**구현**:
- 상태 전이 검증 (활성→종료, 활성→갱신예정 등)
- reason 필드 필수
- 이력 자동 기록 (change_type: '상태변경')
- RBAC 검증 (MANAGER+)

**유효한 상태 전이**:
- 활성 → 종료 (계약 만료)
- 활성 → 갱신예정 (갱신 준비)
- 갱신예정 → 활성 (갱신 완료)
- 종료 → 활성 (재계약)

**응답** (200 OK):
```json
{
  "id": 1,
  "contract_status": "종료",
  "message": "Status updated successfully"
}
```
