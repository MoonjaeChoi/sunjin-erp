# Product Requirement Document: 전체 레이아웃 설정

문서번호: 2001
작성일: 2026-01-24
상위문서: 1000_초안.prd

## 1. Overview

본 PRD는 sunjin-erp 시스템의 "전체 레이아웃 설정" 기능에 대한 요구사항을 정의한다.
이 기능은 모든 페이지의 공통 UI 구조(사이드바, 헤더, 콘텐츠 영역)를 정의하고, 인증 상태에 따른 레이아웃 분기와 역할 기반 네비게이션을 제공하는 애플리케이션 쉘(App Shell)을 구축한다.

**대상 모듈:** 공통 레이아웃 (전체 시스템)
**대상 사용자 역할:** ADMIN / MANAGER / USER

## 2. Goals & Objectives

* **일관된 UI 구조 제공:** 모든 인증된 페이지에서 동일한 사이드바 + 헤더 + 콘텐츠 레이아웃을 유지한다.
* **인증 상태별 레이아웃 분기:** 비인증 사용자는 로그인 전용 레이아웃, 인증 사용자는 메인 레이아웃을 표시한다.
* **역할 기반 네비게이션:** 사용자 권한(ADMIN/MANAGER/USER)에 따라 접근 가능한 메뉴를 동적으로 제어한다.
* **반응형 지원:** Desktop(1280px+) 우선 설계, Tablet(768px+) 지원, 사이드바 축소/확장 가능.
* **빠른 네비게이션:** 클라이언트 사이드 라우팅으로 페이지 전환 시 레이아웃 리렌더링 없이 콘텐츠만 교체한다.

## 3. User Stories / Use Cases

* **US-1:** 인증된 사용자로서, 로그인 후 사이드바와 헤더가 있는 메인 레이아웃을 볼 수 있다. 그래서 각 모듈에 빠르게 접근할 수 있다.
    * *Acceptance Criteria:*
        * 로그인 성공 시 대시보드 페이지로 이동하며 사이드바 + 헤더가 표시된다
        * 사이드바에 10개 모듈 메뉴가 표시된다
        * 현재 활성 메뉴가 시각적으로 구분된다

* **US-2:** 비인증 사용자로서, 로그인 페이지에서는 사이드바/헤더 없이 로그인 폼만 표시된다.
    * *Acceptance Criteria:*
        * 인증되지 않은 상태에서 모든 (main) 경로 접근 시 로그인 페이지로 리다이렉트된다
        * 로그인 페이지는 중앙 정렬된 단일 카드 레이아웃이다

* **US-3:** 사용자로서, 사이드바를 축소(collapse)하여 콘텐츠 영역을 넓게 사용할 수 있다.
    * *Acceptance Criteria:*
        * 사이드바 토글 버튼으로 축소/확장 전환 가능
        * 축소 시 아이콘만 표시, 확장 시 아이콘 + 텍스트 표시
        * 축소/확장 상태가 로컬에 유지된다 (새로고침 후에도 유지)

* **US-4:** ADMIN 역할 사용자로서, 직원 관리 메뉴를 볼 수 있다. 일반 USER는 해당 메뉴가 표시되지 않는다.
    * *Acceptance Criteria:*
        * ADMIN: 전체 메뉴 접근 가능
        * MANAGER: 직원 관리 메뉴 읽기 전용 (부서 내)
        * USER: 직원 관리 메뉴 미표시

* **US-5:** 사용자로서, 헤더에서 본인의 이름, 역할을 확인하고 로그아웃할 수 있다.
    * *Acceptance Criteria:*
        * 헤더 우측에 사용자 이름 및 역할 배지 표시
        * 프로필 드롭다운 메뉴에서 로그아웃 가능
        * 로그아웃 시 세션 종료 후 로그인 페이지로 이동

* **US-6:** Tablet 환경의 사용자로서, 사이드바가 오버레이 형태로 열리고 콘텐츠 영역을 가리지 않는다.
    * *Acceptance Criteria:*
        * 768px 미만에서 사이드바는 기본 숨김 상태
        * 햄버거 메뉴 클릭 시 오버레이로 사이드바 표시
        * 메뉴 선택 또는 외부 클릭 시 사이드바 자동 닫힘

## 4. Scope

### 4.1 In-Scope

* Next.js App Router Route Group 레이아웃 구조 (`(auth)`, `(main)`)
* 사이드바 네비게이션 컴포넌트 (축소/확장, 역할 기반 필터링)
* 헤더 컴포넌트 (사용자 정보, 로그아웃, 사이드바 토글)
* 메인 콘텐츠 영역 레이아웃 (스크롤, 패딩, 최대 너비)
* Breadcrumb 네비게이션
* 반응형 디자인 (Desktop / Tablet)
* 사이드바 상태 영속성 (localStorage)
* 인증 상태 기반 리다이렉트 (middleware)

### 4.2 Out-of-Scope

* 각 모듈의 실제 페이지 콘텐츠 구현
* 알림(Notification) 시스템
* 다국어(i18n) 지원
* 다크 모드 / 테마 전환
* 모바일(< 768px) 전용 레이아웃

## 5. Technical Considerations & Architecture Alignment

### 5.1 Next.js App Router Structure

* **Route Groups:**
    - `src/app/(auth)/layout.tsx` — 인증 전 레이아웃 (로그인 전용, 사이드바/헤더 없음)
    - `src/app/(auth)/login/page.tsx` — 로그인 페이지
    - `src/app/(main)/layout.tsx` — 인증 후 메인 레이아웃 (사이드바 + 헤더 + 콘텐츠)
    - `src/app/(main)/dashboard/page.tsx` — 기본 랜딩 페이지

* **Root Layout:** `src/app/layout.tsx`
    - HTML/Body 태그, 폰트 설정, TanStack Query Provider, NextAuth SessionProvider 포함
    - Toaster (알림 토스트) 글로벌 렌더링

* **Middleware:** `src/middleware.ts`
    - NextAuth 세션 확인
    - 미인증 사용자 → `/login` 리다이렉트
    - 인증된 사용자의 `/login` 접근 → `/dashboard` 리다이렉트

### 5.2 API Route Handlers

* `GET /api/auth/session` — 현재 세션 정보 조회 (NextAuth 제공)
* `POST /api/auth/signout` — 로그아웃 처리 (NextAuth 제공)

### 5.3 Database (Oracle XE 21c + TypeORM)

* 레이아웃 자체는 DB 의존성 없음
* 사이드바 메뉴 구성은 정적 정의 (코드 내 상수)
* 사용자 정보(이름, 역할, 부서)는 NextAuth session에서 제공

### 5.4 State Management

* **Zustand Store:** `useSidebarStore`
    - `isCollapsed: boolean` — 사이드바 축소 상태
    - `isMobileOpen: boolean` — 모바일/태블릿 오버레이 상태
    - `toggle()` — 축소/확장 전환
    - `setMobileOpen(open: boolean)` — 모바일 사이드바 열기/닫기
    - localStorage persist middleware로 상태 유지

* **Server State:** 없음 (레이아웃은 순수 클라이언트 UI)

### 5.5 Authentication & Authorization

* **NextAuth.js:** Session 객체에 `user.role`, `user.name`, `user.department` 포함
* **Middleware:** `src/middleware.ts`에서 route-level 보호
* **Menu Visibility:** 사이드바 메뉴 항목별 `requiredRole` 속성으로 필터링

### 5.6 네비게이션 메뉴 구조

사이드바에 표시될 메뉴 항목:

## 6. UI/UX Considerations

### 6.1 Component Library

* **shadcn/ui 활용 컴포넌트:**
    - `Button` — 사이드바 토글, 로그아웃
    - `Avatar` — 사용자 프로필 아이콘
    - `DropdownMenu` — 사용자 메뉴 (로그아웃, 프로필)
    - `Tooltip` — 사이드바 축소 시 메뉴명 표시
    - `Separator` — 메뉴 그룹 구분
    - `Sheet` — 모바일 사이드바 오버레이
    - `Breadcrumb` — 현재 위치 표시

* **Lucide React Icons:** 각 메뉴별 아이콘 적용

### 6.2 레이아웃 구조

```
┌─────────────────────────────────────────────────┐
│ Header (h-14)                                    │
│  [☰ Toggle] [Breadcrumb]          [User ▾]      │
├────────┬────────────────────────────────────────┤
│        │                                         │
│ Side   │  Main Content Area                      │
│ bar    │  (p-6, max-w-7xl, overflow-y-auto)      │
│ (w-64  │                                         │
│  or    │  ┌─────────────────────────────────┐   │
│  w-16) │  │  Page Content (children)        │   │
│        │  │                                   │   │
│        │  └─────────────────────────────────┘   │
│        │                                         │
└────────┴────────────────────────────────────────┘
```

* **사이드바 확장:** width 256px (w-64), 아이콘 + 텍스트
* **사이드바 축소:** width 64px (w-16), 아이콘만 (hover tooltip)
* **헤더 높이:** 56px (h-14), 하단 border
* **콘텐츠 영역:** 나머지 전체 높이, 내부 스크롤

### 6.3 Responsive Design

| Breakpoint | 사이드바 동작 | 헤더 동작 |
|------------|--------------|-----------|
| Desktop (1280px+) | 고정 표시, 축소/확장 가능 | 전체 표시 |
| Tablet (768px~1279px) | 기본 축소, 확장 가능 | 전체 표시 |
| Small Tablet (< 768px) | 숨김, Sheet 오버레이로 표시 | 햄버거 메뉴 표시 |

### 6.4 User Feedback

* **Active Route:** 현재 페이지에 해당하는 사이드바 메뉴 항목에 배경색 하이라이트 + 좌측 인디케이터
* **Hover Effect:** 메뉴 항목 hover 시 배경색 변화
* **Transition:** 사이드바 축소/확장 시 width transition (200ms ease)

## 7. Success Metrics

* **레이아웃 렌더링 안정성:** 페이지 전환 시 레이아웃 깜빡임(flash) 없음
* **라우팅 성능:** 클라이언트 사이드 페이지 전환 시간 < 100ms (레이아웃 리렌더링 없이)
* **반응형 정확도:** 모든 breakpoint에서 레이아웃 깨짐 없음
* **Technical Performance:**
    * Layout Shift: CLS < 0.1
    * First Contentful Paint: FCP < 1.5s
    * 사이드바 인터랙션 응답: < 50ms

## 8. Security Considerations

* **Authentication:** NextAuth.js middleware로 모든 `(main)` 경로 보호, 미인증 시 로그인 페이지로 리다이렉트
* **Authorization:** 사이드바 메뉴 렌더링 시 session.user.role 기반 필터링 (클라이언트 + 서버 양측 검증)
* **Session Expiry:** 세션 만료 시 자동 로그아웃 처리 및 로그인 페이지 리다이렉트
* **Route Protection:** 메뉴 숨김만으로는 불충분 — API Route 및 Page 레벨에서도 권한 검증 필수
