## 구현 내용

### 1. GET /api/maintenance/[id] - 계약 상세 조회

**권한**: USER+ (모든 사용자)

**응답**:
```json
{
  "id": 1,
  "customer": { "id": 1, "name": "ABC Corp" },
  "contract_name": "유지보수계약",
  "start_date": "2026-01-01",
  "end_date": "2026-12-31",
  "contract_status": "활성",
  "assignedEmployee": { "id": 1, "name": "김영희" },
  "createdBy": { "id": 1, "name": "김영희" },
  "createdAt": "2026-01-01T00:00:00Z"
}
```

### 2. PUT /api/maintenance/[id] - 계약 정보 수정

**권한**: MANAGER+ (MANAGER, ADMIN)

**요청**:
```json
{
  "contract_name": "수정된 계약명",
  "end_date": "2027-12-31",
  "contract_amount": 6000000,
  "assigned_employee_id": 2,
  "contract_status": "갱신예정",
  "notes": "수정사항"
}
```

**특징**:
- customer_id는 수정 불가 (고정)
- end_date 변경시 갱신 이력 자동 기록
- status 변경시 상태변경 이력 기록

### 3. DELETE /api/maintenance/[id] - 소프트 삭제

**권한**: ADMIN만

**특징**:
- Cascade soft delete (계약 + 첨부 + 이력)
- 삭제 확인 다이얼로그 필수
- 삭제 이력 자동 기록
