### 1. maintenance/page.tsx - 계약 목록 페이지

**목적**: 유지보수 계약 목록을 표시하고 필터링, 정렬, 페이지네이션을 제공합니다.

**구현 명세**:

```typescript
// src/app/(main)/maintenance/page.tsx

import { Suspense } from 'react';
import { redirect } from 'next/navigation';
import { getServerSession } from 'next-auth';
import MaintenanceListPageClient from './page.client';
import { MaintenanceListSkeleton } from '@/components/features/maintenance/skeletons';

export const metadata = {
  title: 'Maintenance Contracts | Sunjin ERP',
  description: 'Manage maintenance contracts',
};

export default async function MaintenanceListPage(props: {
  searchParams: { [key: string]: string | string[] | undefined };
}) {
  // 1. 세션 검증
  const session = await getServerSession();
  if (!session?.user) {
    redirect('/login');
  }

  // 2. 권한 검증 (USER+)
  if (!['USER', 'MANAGER', 'ADMIN'].includes(session.user.role)) {
    redirect('/');
  }

  // 3. URL 파라미터 파싱
  const searchParams = props.searchParams;
  const status = typeof searchParams.status === 'string' ? searchParams.status : undefined;
  const assignedEmployeeId = typeof searchParams.assignedEmployeeId === 'string'
    ? searchParams.assignedEmployeeId
    : undefined;
  const customerId = typeof searchParams.customerId === 'string' ? searchParams.customerId : undefined;
  const contractNameSearch = typeof searchParams.contractNameSearch === 'string'
    ? searchParams.contractNameSearch
    : '';
  const startDateFrom = typeof searchParams.startDateFrom === 'string'
    ? searchParams.startDateFrom
    : undefined;
  const startDateTo = typeof searchParams.startDateTo === 'string'
    ? searchParams.startDateTo
    : undefined;
  const endDateFrom = typeof searchParams.endDateFrom === 'string'
    ? searchParams.endDateFrom
    : undefined;
  const endDateTo = typeof searchParams.endDateTo === 'string'
    ? searchParams.endDateTo
    : undefined;
  const sortBy = typeof searchParams.sortBy === 'string' ? searchParams.sortBy : 'endDate';
  const order = typeof searchParams.order === 'string' ? searchParams.order : 'DESC';
  const page = typeof searchParams.page === 'string' ? parseInt(searchParams.page, 10) : 1;
  const limit = typeof searchParams.limit === 'string' ? parseInt(searchParams.limit, 10) : 20;

  return (
    <div className="space-y-4 p-4">
      <div className="flex justify-between items-center">
        <h1 className="text-3xl font-bold">유지보수 고객 관리</h1>
        {['MANAGER', 'ADMIN'].includes(session.user.role) && (
          <a href="/maintenance/new" className="btn btn-primary">
            신규 계약 추가
          </a>
        )}
      </div>

      <Suspense fallback={<MaintenanceListSkeleton />}>
        <MaintenanceListPageClient
          session={session}
          initialFilters={{
            status,
            assignedEmployeeId,
            customerId,
            contractNameSearch,
            startDateFrom,
            startDateTo,
            endDateFrom,
            endDateTo,
            sortBy,
            order,
            page,
            limit,
          }}
        />
      </Suspense>
    </div>
  );
}
```

**세부사항**:
- 세션 검증 (미인증 시 /login으로 redirect)
- 권한 검증 (USER+ 만 접근)
- URL searchParams를 Client Component에 props로 전달
- Suspense + 스켈레톤 UI로 로딩 상태 처리

### 3. maintenance/[id]/page.tsx - 계약 상세 페이지

**목적**: 특정 계약의 상세 정보, 첨부 파일, 갱신 이력을 표시합니다.

**구현 명세**:

```typescript
// src/app/(main)/maintenance/[id]/page.tsx

import { notFound, redirect } from 'next/navigation';
import { getServerSession } from 'next-auth';
import { getDataSource } from '@/lib/db';
import MaintenanceDetailPageClient from './page.client';
import { DetailPageSkeleton } from '@/components/features/maintenance/skeletons';
import { Suspense } from 'react';
import { IsNull } from 'typeorm';

export const metadata = {
  title: 'Contract Detail | Maintenance | Sunjin ERP',
};

export default async function MaintenanceDetailPage(props: {
  params: { id: string };
}) {
  // 1. 세션 검증
  const session = await getServerSession();
  if (!session?.user) {
    redirect('/login');
  }

  // 2. 권한 검증 (USER+)
  if (!['USER', 'MANAGER', 'ADMIN'].includes(session.user.role)) {
    redirect('/');
  }

  // 3. 계약 조회
  const contractId = parseInt(props.params.id, 10);
  if (isNaN(contractId)) {
    notFound();
  }

  const dataSource = await getDataSource();
  const contract = await dataSource
    .getRepository('MaintenanceContract')
    .createQueryBuilder('mc')
    .leftJoinAndSelect('mc.customer', 'customer')
    .leftJoinAndSelect('mc.assignedEmployee', 'employee')
    .leftJoinAndSelect('mc.createdBy', 'createdBy')
    .leftJoinAndSelect('mc.updatedBy', 'updatedBy')
    .where('mc.id = :id', { id: contractId })
    .andWhere('mc.deleted_at IS NULL')
    .getOne();

  if (!contract) {
    notFound();
  }

  // 4. 행 레벨 권한 검증 (필요 시)
  // 현재는 오픈 액세스 (모든 MANAGER가 모든 계약 수정 가능)
  // Phase 2: 부서별 액세스 제어 추가

  return (
    <div className="space-y-4 p-4">
      <div className="mb-6">
        <h1 className="text-3xl font-bold">{contract.contract_name}</h1>
        <p className="text-gray-600 mt-2">
          고객사: <strong>{contract.customer.name}</strong>
        </p>
      </div>

      <Suspense fallback={<DetailPageSkeleton />}>
        <MaintenanceDetailPageClient
          contract={contract}
          session={session}
        />
      </Suspense>
    </div>
  );
}
```

**세부사항**:
- 계약 ID 유효성 검증
- 데이터베이스에서 계약 조회 (soft-delete 제외)
- 존재하지 않으면 notFound()
- 권한 검증 (USER+)
- 계약 데이터를 Client Component에 props로 전달

## 테스트 전략

### 수동 테스트

1. **세션 검증**
   - 쿠키 없이 `/maintenance` 접근 → /login 으로 redirect
   - 로그인 후 `/maintenance` 접근 → 목록 페이지 표시

2. **권한 검증**
   - USER 역할 → `/maintenance/new` 접근 불가 (redirect)
   - MANAGER 역할 → `/maintenance/new` 접근 가능

3. **동적 라우팅**
   - 존재하는 계약 ID → 상세 페이지 표시
   - 존재하지 않는 ID → 404 페이지

4. **Suspense 처리**
   - 페이지 로드 중 스켈레톤 UI 표시
   - 데이터 로드 완료 후 실제 컨텐츠 표시
