### 탭 구성

1. **기본정보 탭**
   - 이름, 이메일, 전화번호, 직무
   - 부서, 직급, 상위 매니저
   - 입사일, 생일
   - 수정 버튼 (ADMIN만)

2. **계정 탭** (ADMIN만)
   - Username, Role, 활성 상태
   - 마지막 로그인, 비밀번호 변경일
   - 권한 변경 버튼
   - 비활성화/활성화 버튼
   - 계정 없으면 생성 폼 표시

3. **이력 탭** (ADMIN만)
   - 변경 이력 테이블
   - 변경 유형, 변경자, 변경 시각
   - 변경된 필드 상세
