## 주요 기술 스택 및 제약사항

### 기술 스택
- **Framework**: Next.js 14 (App Router)
- **Database**: Oracle XE 21c + TypeORM
- **State Management**: TanStack Query (서버), React useState (클라이언트)
- **UI**: shadcn/ui + Tailwind CSS
- **Testing**: Jest + React Testing Library + Playwright

### 핵심 제약사항

1. **Soft Delete 필수**: 모든 삭제는 `deleted_at` 설정 (물리 삭제 금지)
2. **Cascade Soft Delete**: 계약 삭제 시 첨부+이력도 함께 삭제
3. **RBAC 검증**: 3계층 (Server Component, API Route, UI)
4. **URL 기반 필터링**: TanStack Query가 관리하는 Query Parameters
5. **ON DELETE RESTRICT**: 모든 FK에 적용
