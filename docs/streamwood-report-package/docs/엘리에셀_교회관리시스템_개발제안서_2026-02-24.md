## 1. 제안 개요

### 1.1 제안 배경

과천교회는 오랜 기간 Windows PC 기반 교적 관리 프로그램을 성실히 운용해 왔으며, 해당 시스템은 교회 행정의 디지털화 초석을 마련하는 데 큰 역할을 해왔습니다. 축적된 교인 데이터와 운영 노하우는 앞으로도 귀중한 자산으로 계승될 것입니다.

다만 최근 **Windows 11 환경으로의 전환**을 계기로, 설치형 프로그램 특유의 OS 의존성이 가시화되고 있으며, 사무실 외부나 모바일 기기에서는 접근이 어렵다는 환경적 아쉬움도 함께 대두되고 있습니다. 이는 기존 시스템의 결함이라기보다, 시대적 흐름과 사용 환경이 변화한 데 따른 자연스러운 전환점으로 이해할 수 있습니다.

이에 미디어사역위원회 교적사역부는 기존 시스템이 쌓아온 성과를 토대로, 어떤 기기·장소에서도 접근 가능한 **교회 관리 시스템 '시냇가하늘숲'** 으로의 세대 교체를 제안합니다. 본 제안서는 시냇가하늘숲 시스템의 주요 기능과 도입 일정, 운영 방안을 제시합니다.

### 3.4 인프라 구성 — 온프레미스

> **온프레미스(On-Premises)란?**
> 서버를 외부 클라우드에 두지 않고, 교회 내부 공간에 직접 설치·운용하는 방식입니다.
> 교인 개인정보가 교회 건물 밖으로 나가지 않으며, 인터넷 없이도 내부망만으로 운용할 수 있습니다.
>
> **온프레미스 방식의 주요 장점**
> - **개인정보 보호**: 교인 정보가 외부 서버에 저장되지 않아 정보 유출 위험 최소화
> - **데이터 주권**: 모든 데이터를 교회가 직접 소유·통제
> - **월 고정비 없음**: 클라우드 VM 임대료 없이 전기·인터넷 비용만 발생
> - **인터넷 독립성**: 교내 네트워크만 연결되면 외부 인터넷 장애와 무관하게 운용 가능
> - **장기 비용 절감**: 초기 서버 구매 후 추가 비용 없이 수년간 운용 가능

```
교회 내 서버 1대 (미니 PC 폼팩터 권장)
├─ CPU: Intel Core Ultra 7/9 또는 Core i9 13세대 이상 (16코어)
├─ RAM: 32GB DDR5 이상
├─ Storage (OS): NVMe PCIe 4.0 M.2 1TB 이상 (읽기 7,000MB/s+)
├─ Storage (데이터): NVMe PCIe 4.0 M.2 2TB 이상 (DB·백업 전용)

```

### 4.2 주요 모듈 상세

#### 모듈 1: 회계 관리
- **예산 수립**: 연간·분기 예산 계획 수립, 항목별 예산 배정

- **헌금 관리**: 교인별 헌금 내역 등록·조회, 헌금 유형별 분류 (주일·감사·십일조 등)

#### 모듈 2: 전자결재

- **반려·재기안**: 반려 사유 기록, 수정 후 재기안 처리
- **결재 현황**: 진행 중·완료·반려 문서 목록 조회, 결재 이력 관리

#### 모듈 4: 교인 관리
- **교인 등록**: 기본정보 → 추가정보 → 완료 3단계 마법사

- **제적 관리**: 제적 사유·복적 처리

- **QR/바코드 스캔**: 예배 현장 실시간 체크인, 생일 알림
