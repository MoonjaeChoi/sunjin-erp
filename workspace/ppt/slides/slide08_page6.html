장애 현황 관리 (PRD 2051)

Phase 1 구현 완료

  • 장애 CRUD: 생성/조회/수정/삭제
  • 상태 관리: INTAKE-COMPLETED
  • 심각도 관리: 4단계 우선순위
  • 고객사 연동: FK, 필터링
  • 담당자 할당: 권한별 제약
  • 첨부파일 관리: 다중 파일, 10MB
  • 변경 이력: 상태/담당자 기록
  • 요약 API: 상태별 카운트
  • RBAC 권한: ADMIN/MANAGER/USER

Out-of-Scope (Phase 2)

  • 실시간 알림: WebSocket/SSE 필요
  • 메일 발송: nodemailer 미연동

  • 다국어 지원: 한글만
  • 모바일 전용 UI: 반응형만
  • 댓글/코멘트: 이력만 기록
  • SLA 자동 계산: RTO/RTR 미구현
  • Excel/PDF 리포트: Phase 2
