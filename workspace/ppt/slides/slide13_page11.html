공지사항 - 게시판 (PRD 2101)

Phase 1 구현 완료

  • 공지사항 CRUD: 생성/조회/수정/삭제
  • 게시물 유형: 공지/공유/지시/건의/자유
  • 댓글 기능: 트리 구조, 2단계 깊이
  • 첨부파일 관리: 매직 바이트, 10MB/5개
  • 검색/필터링: 제목/내용, 유형/작성자
  • 조회수 추적: 상세 조회 시 증가
  • Draft 자동 저장: localStorage 30초
  • RBAC 권한: MANAGER+(작성)

Out-of-Scope (Phase 2)

  • 좋아요/싫어요: LIKE 테이블 없음
  • 카테고리 추가: 5가지 고정만
  • 알림 시스템: 알림 테이블 없음
  • 대량 import/export: CSV/Excel 없음
  • WYSIWYG 에디터: Textarea만
  • 댓글 좋아요: COMMENT_LIKE 없음
  • 게시물 핀 고정: pinned_at 없음
  • 태그 시스템: TAG 테이블 없음
  • 클라우드 스토리지: 로컬 파일만
