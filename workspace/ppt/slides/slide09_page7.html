재고 관리 (PRD 2061)

Phase 1 구현 완료

  • 재고 CRUD: 입고/조회/수정/삭제
  • 상태 관리: 재고-출고-폐기
  • 이력 추적: 입고/출고/반납 기록
  • 출고/반납 처리: 사용처, 반납 예정일
  • 위치 변경: 이전/새 위치 이력
  • 통계 조회: 상태별 카운트
  • 필터/검색/정렬: 카테고리, 상태, 위치
  • 역할 기반 제어: ADMIN/MANAGER/USER

Out-of-Scope (Phase 2)

  • 바코드/QR 스캔: 수동 입력만
  • 자동 알림: 과기 집계만
  • 장비 예약 시스템: Phase 2
  • 승인 워크플로우: 즉시 실행만
  • 장비 모니터링: Phase 2
  • 외부 ERP 연동: Phase 2
  • 감가상각 계산: 로직 없음
  • 전문검색(FTS): LIKE만
  • 부서별 권한: 전사 접근만
