유지보수 고객 관리 (PRD 2071)

Phase 1 구현 완료

  • 유지보수 CRUD: 생성/조회/수정/삭제
  • 계약 상태 관리: 활성/종료/갱신예정
  • 고객사 연동: FK, 필터링
  • 계약 기간 관리: 시작일/종료일 이력
  • 첨부파일 관리: PDF/DOC, 10MB
  • 변경 이력 추적: 갱신/상태변경 기록
  • 기본 통계: 30/60일 만료 알림
  • 역할 기반 제어: USER/MANAGER/ADMIN

Out-of-Scope (Phase 2)

  • 자동 상태 전이: 수동 변경만
  • 자동 계약 갱신: 수동 renewContract
  • 매출 인식: 회계 연동 없음
  • 전자서명: 서명 필드 없음
  • 분석 대시보드: 기본 통계만
  • 다국어 지원: 한글만
  • 부서별 액세스: 역할만
  • 파일 버전 관리: 메타데이터만
  • 대량 작업: 개별 처리만
