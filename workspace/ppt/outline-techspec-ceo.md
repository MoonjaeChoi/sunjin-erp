### Slide 4: 핵심 모듈 (11개)
- **업무 관리**: 대시보드, 업무 검색, 캘린더
- **고객 관리**: 고객 등록, 담당자, CRM
- **영업 지원**: 프로젝트(Sales Pipeline), 기술지원
- **운영 관리**: 장애관리, 재고관리, 유지보수
- **기타**: 직원관리, 공지사항

### Slide 5: 기술 아키텍처
- **Frontend**: Next.js 14 + TypeScript
- **UI**: shadcn/ui + Tailwind CSS
- **Backend**: Next.js API Routes
- **Database**: Oracle XE 21c
- **배포**: Docker + Docker Compose

### Slide 6: 보안 및 권한
- **인증**: JWT 기반 세션 관리
- **권한 체계**:
  - ADMIN: 전체 기능 + 시스템 관리
  - MANAGER: 부서 내 데이터 관리
  - USER: 본인 데이터 + 읽기 권한
