# /prd-mediator

## Purpose

**Interactive PRD Discussion Mediator** - Facilitates collaborative decision-making on discussion topics extracted by `/prd-rebuttal-agent`, enabling user-driven or AI-assisted resolution, then automatically updates the PRD v2.md file with finalized decisions.

## How It Works

This command transforms discussion topics into **actionable decisions** through:

1. **Topic Analysis**: Parses discussion topics by priority (HIGH/MEDIUM/LOW)
2. **Decision Options**: Presents each topic with clear options and sunjin-erp context
3. **User Engagement**: Uses interactive questions for high-priority items
4. **AI Assistance**: Optional AI recommendations for faster decision-making
5. **Decision Documentation**: Records final decisions with rationale
6. **PRD Integration**: Updates PRD v2.md with finalized decisions

## Input Requirements

- **`--dis` / `--discussion-topics`** (Required): Path to discussion topics file
  - Generated by `/prd-rebuttal-agent --dis` command
  - Example: `docs/prd/1020_기술지원_관리_prd_discussion_topics.md`

- **`--prd-v2` / `--prd-file`** (Optional): Path to PRD v2 file to update
  - If not provided, uses auto-detected path from discussion topics filename
  - Example: `docs/prd/1020_기술지원_관리_prd_v2.md`

- **`--mode` / `--decision-mode`** (Optional): Decision-making mode
  - `user` (default): User makes all decisions via interactive questions
  - `ai-assisted`: Claude suggests decisions with user confirmation
  - `auto`: Claude makes decisions based on best practices (minimal user input)

- **`--priority` / `--pri`** (Optional): Filter discussion items by priority
  - `high`: HIGH priority items only (blockers + critical)
  - `medium`: MEDIUM priority items only
  - `low`: LOW priority items only
  - `all` (default): All items regardless of priority

## Usage Examples

### Basic Usage - Interactive Decision Making

```bash
/prd-mediator --dis docs/prd/1020_기술지원_관리_prd_discussion_topics.md
```

**Process:**
1. Parse HIGH priority items first
2. Present each with options and context
3. User selects decision via interactive prompts
4. Proceed to MEDIUM priority items
5. Generate decision document
6. Update PRD v2.md

**Auto-generates:**
- `docs/prd/1020_기술지원_관리_prd_decisions.md` - Decision record with rationale
- `docs/prd/1020_기술지원_관리_prd_v2_updated.md` - Updated PRD with decisions applied

### HIGH Priority Only - For Blockers

```bash
/prd-mediator --dis docs/prd/1020_기술지원_관리_prd_discussion_topics.md --priority high
```

**Process:**
- Focus on HIGH priority items only (blocking implementation)
- Quick decision-making on critical issues
- MEDIUM/LOW items deferred

### AI-Assisted Decision Making

```bash
/prd-mediator --dis docs/prd/1020_기술지원_관리_prd_discussion_topics.md --mode ai-assisted
```

**Process:**
1. Claude analyzes each discussion topic
2. Provides recommended decision with reasoning based on sunjin-erp guidelines
3. User confirms or overrides each decision
4. Auto-applies all decisions to PRD v2.md

**Benefit:** Faster than pure user-driven, maintains human oversight

### Fully Automated - AI Makes All Decisions

```bash
/prd-mediator --dis docs/prd/1020_기술지원_관리_prd_discussion_topics.md --mode auto
```

**Process:**
1. Claude analyzes all discussion topics
2. Makes decisions based on sunjin-erp best practices
3. No user interaction (minimal time investment)
4. Generates comprehensive decision log for review

**Benefit:** Fastest path - suitable when clear best practices exist

## Interactive Decision Flow Example

### HIGH Priority Item #1 - Database Entity Design

```
Decision: TypeORM Entity 설계 전략 (CRITICAL)

Issue: 기술지원(TechSupport) entity의 다형적 관계 설계 방식

Options:

   [A] 단일 테이블 상속 (Single Table Inheritance)
       Pros: 쿼리 단순, JOIN 불필요
       Cons: NULL column 다수, 테이블 비대화
       sunjin-erp Alignment: Oracle XE 23 성능 우수

   [B] 테이블별 분리 (Table Per Type)
       Pros: 정규화 원칙 준수, 각 테이블 명확
       Cons: JOIN 필요, 쿼리 복잡도 증가
       sunjin-erp Alignment: 유지보수 용이

   [C] 공통 테이블 + 상세 테이블 (Joined Strategy)
       Pros: 공통 필드 재사용, 확장성 우수
       Cons: 설계 복잡도
       sunjin-erp Alignment: ERP 모듈 확장에 적합

AI Recommendation: Option C (ERP 확장성 고려)

Select: [A/B/C] or [?] for more info
```

## Key Features

- **Interactive Questions**: Uses AskUserQuestion for each decision
- **AI Recommendations**: Claude analysis based on sunjin-erp best practices
- **Decision Rationale**: Documents why each decision was made
- **PRD Integration**: Automatically updates PRD v2.md with applied decisions
- **Priority-Based**: Handle blockers first, defer non-critical items
- **sunjin-erp Context**: Decisions aligned with Next.js App Router, Oracle XE 23, TypeORM, NextAuth.js RBAC

## Notes

- Decisions are documented and reversible
- Use `--mode user` when stakeholder input is critical
- Use `--mode auto` with `--priority high` for fast-track blocker resolution
- Always review decision document before final PRD approval
