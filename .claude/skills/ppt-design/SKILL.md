# PPT 디자인 스킬

이 스킬은 일반적인 "AI 슬롭" 미학을 피하고 독특하고 프로덕션 수준의 프리젠테이션 디자인을 생성하기 위한 가이드입니다.

## 디자인 사고 프로세스

코드를 작성하기 전에 컨텍스트를 이해하고 **대담한** 미적 방향을 선택하세요:

- **목적**: 이 프리젠테이션이 해결하는 문제는? 대상 청중은?
- **톤**: 극단적인 방향 선택: 미니멀리즘, 맥시멀리즘, 레트로-퓨처리스틱, 오가닉/자연적, 럭셔리/세련됨, 플레이풀/장난감 같은, 에디토리얼/매거진, 브루탈리스트/로우, 아르데코/기하학적, 소프트/파스텔, 인더스트리얼/실용적 등
- **제약조건**: 기술적 요구사항 (프레임워크, 성능, 접근성)
- **차별화**: 이 디자인을 **잊을 수 없게** 만드는 요소는? 사람들이 기억할 한 가지는?

**핵심 원칙**: 명확한 개념적 방향을 선택하고 정밀하게 실행하세요. 대담한 맥시멀리즘과 세련된 미니멀리즘 모두 효과적입니다 - 핵심은 **의도성**이지 강도가 아닙니다.

## 프론트엔드 미학 가이드라인

### 타이포그래피

- 아름답고 독특하며 흥미로운 폰트 선택
- **절대 사용하지 말 것**: Arial, Inter, Roboto, 시스템 폰트 같은 제네릭 폰트
- 개성 있고 예상치 못한 폰트 조합 선택
- 디스플레이 폰트와 본문 폰트를 세심하게 페어링

### 컬러 & 테마

- 일관된 미학에 전념
- CSS 변수 사용으로 일관성 유지
- 소심하게 고르게 분배된 팔레트보다 **지배적 컬러 + 날카로운 악센트** 선호
- 클리셰 컬러 스킴 피하기 (특히 흰색 배경에 보라색 그라데이션)

### 모션 & 애니메이션

- 효과와 마이크로 인터랙션에 애니메이션 사용
- HTML에서는 CSS 전용 솔루션 우선
- 고임팩트 순간에 집중: 산발적인 마이크로 인터랙션보다 잘 조율된 페이지 로드와 시차 효과가 더 효과적
- 스크롤 트리거링과 놀라움을 주는 호버 상태 활용

### 공간 구성

- 예상치 못한 레이아웃
- 비대칭
- 오버랩
- 대각선 흐름
- 그리드를 깨는 요소
- 넉넉한 네거티브 스페이스 또는 제어된 밀도

### 배경 & 비주얼 디테일

- 단색 기본값 대신 분위기와 깊이 창조
- 전체 미학에 맞는 맥락적 효과와 텍스처 추가
- 그라데이션 메시, 노이즈 텍스처, 기하학적 패턴
- 레이어드 투명도, 드라마틱한 그림자
- 장식적 테두리, 커스텀 커서, 그레인 오버레이

## 절대 하지 말아야 할 것

일반적인 AI 생성 미학 피하기:
- 과도하게 사용되는 폰트 패밀리 (Inter, Roboto, Arial, 시스템 폰트)
- 클리셰 컬러 스킴 (특히 흰색 배경에 보라색 그라데이션)
- 예측 가능한 레이아웃과 컴포넌트 패턴
- 맥락 특정 캐릭터가 없는 쿠키커터 디자인

**절대로** 공통 선택에 수렴하지 마세요 (예: Space Grotesk). 밝은 테마와 어두운 테마, 다른 폰트, 다른 미학 사이에서 변화를 주세요.

## 구현 복잡성 매칭

**중요**: 구현 복잡성을 미적 비전에 맞추세요:
- **맥시멀리스트 디자인**: 광범위한 애니메이션과 효과가 있는 정교한 코드 필요
- **미니멀리스트/세련된 디자인**: 절제, 정밀함, 간격, 타이포그래피, 미묘한 디테일에 세심한 주의 필요

우아함은 비전을 잘 실행하는 것에서 나옵니다.

## PPT 특화 디자인 원칙

### 컬러 팔레트 선택

**창의적으로 컬러 선택하기**:
- 기본값을 넘어 생각하세요 - 이 특정 주제에 진정으로 맞는 컬러는?
- 여러 각도 고려: 주제, 산업, 분위기, 에너지 레벨, 대상 청중, 브랜드 아이덴티티
- 모험적으로: 예상치 못한 조합 시도 - 헬스케어 프레젠테이션이 초록색일 필요 없고, 금융이 네이비일 필요 없음
- 팔레트 구축: 함께 작동하는 3-5개 컬러 선택 (지배색 + 보조 톤 + 악센트)
- 대비 보장: 텍스트가 배경에서 명확하게 읽혀야 함

### 비주얼 디테일 옵션

**기하학적 패턴**:
- 수평 대신 대각선 섹션 디바이더
- 비대칭 컬럼 너비 (30/70, 40/60, 25/75)
- 90° 또는 270° 회전된 텍스트 헤더
- 이미지용 원형/육각형 프레임
- 모서리의 삼각형 악센트 형태
- 깊이를 위한 겹치는 형태

**테두리 & 프레임 처리**:
- 한 면에만 두꺼운 단색 테두리 (10-20pt)
- 대비 컬러의 이중선 테두리
- 전체 프레임 대신 코너 브라켓
- L자형 테두리 (위+왼쪽 또는 아래+오른쪽)
- 헤더 아래 밑줄 악센트 (3-5pt 두께)

**타이포그래피 처리**:
- 극단적 크기 대비 (72pt 헤드라인 vs 11pt 본문)
- 넓은 자간의 대문자 헤더
- 초대형 디스플레이 타입의 번호 섹션
- 데이터/통계/기술 콘텐츠용 모노스페이스 (Courier New)
- 밀집된 정보용 좁은 폰트 (Arial Narrow)
- 강조를 위한 아웃라인 텍스트

**차트 & 데이터 스타일링**:
- 핵심 데이터에 단일 악센트 컬러를 사용한 모노크롬 차트
- 세로 막대 차트 대신 가로 막대 차트
- 막대 차트 대신 점 도표
- 최소한의 그리드선 또는 없음
- 요소에 직접 데이터 라벨 (범례 없이)
- 핵심 메트릭용 초대형 숫자

**레이아웃 혁신**:
- 텍스트 오버레이가 있는 풀 블리드 이미지
- 네비게이션/컨텍스트용 사이드바 컬럼 (20-30% 너비)
- 모듈러 그리드 시스템 (3x3, 4x4 블록)
- Z 패턴 또는 F 패턴 콘텐츠 흐름
- 컬러 형태 위에 떠 있는 텍스트 박스
- 매거진 스타일 다중 컬럼 레이아웃

**배경 처리**:
- 슬라이드의 40-60%를 차지하는 단색 블록
- 그라데이션 필 (수직 또는 대각선만)
- 분할 배경 (두 컬러, 대각선 또는 수직)
- 가장자리에서 가장자리까지 컬러 밴드
- 디자인 요소로서의 네거티브 스페이스

## 레이아웃 팁

**차트나 테이블이 있는 슬라이드 만들 때:**

- **투 컬럼 레이아웃 (권장)**: 전체 너비에 걸친 헤더 사용, 그 아래 두 컬럼 - 한 컬럼에 텍스트/불릿, 다른 컬럼에 주요 콘텐츠. 더 나은 균형 제공하고 차트/테이블을 더 읽기 쉽게 만듦. 각 콘텐츠 유형에 공간을 최적화하기 위해 불균등 컬럼 너비 (예: 40%/60% 분할)로 플렉스박스 사용.

- **풀 슬라이드 레이아웃**: 주요 콘텐츠 (차트/테이블)가 전체 슬라이드를 차지하여 최대 임팩트와 가독성 제공

- **절대 수직으로 쌓지 말 것**: 단일 컬럼에서 텍스트 아래에 차트/테이블 배치하지 않기 - 가독성과 레이아웃 문제 유발
