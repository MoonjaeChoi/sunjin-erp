# PPT 디자인 스킬

이 스킬은 일반적인 "AI 슬롭" 미학을 피하고 독특하고 프로덕션 수준의 프리젠테이션 디자인을 생성하기 위한 가이드입니다.

## 디자인 사고 프로세스

코드를 작성하기 전에 컨텍스트를 이해하고 **대담한** 미적 방향을 선택하세요:

- **목적**: 이 프리젠테이션이 해결하는 문제는? 대상 청중은?
- **톤**: 극단적인 방향 선택
  - 미니멀리즘 / 맥시멀리즘
  - 레트로-퓨처리스틱 / 오가닉/자연적
  - 럭셔리/세련됨 / 플레이풀/장난감 같은
  - 에디토리얼/매거진 / 브루탈리스트/로우
  - 아르데코/기하학적 / 소프트/파스텔
  - 인더스트리얼/실용적
- **제약조건**: 기술적 요구사항 (프레임워크, 성능, 접근성)
- **차별화**: 이 디자인을 **잊을 수 없게** 만드는 요소는?

**핵심 원칙**: 명확한 개념적 방향을 선택하고 정밀하게 실행하세요. 대담한 맥시멀리즘과 세련된 미니멀리즘 모두 효과적입니다 - 핵심은 **의도성**이지 강도가 아닙니다.

## 타이포그래피 (필수)

### Pretendard 폰트 사용 (고정)

**모든 PPT 슬라이드는 Pretendard 폰트를 사용합니다.**

```css
/* HTML 슬라이드에서 Pretendard 로드 */
@import url('https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css');

body {
  font-family: 'Pretendard', -apple-system, BlinkMacSystemFont, sans-serif;
}
```

### Pretendard 폰트 웨이트

| 웨이트 | 용도 |
|--------|------|
| 100 (Thin) | 장식적 대형 텍스트 |
| 200 (ExtraLight) | 부제목, 캡션 |
| 300 (Light) | 본문 (밝은 배경) |
| 400 (Regular) | 일반 본문 |
| 500 (Medium) | 강조 본문, 소제목 |
| 600 (SemiBold) | 중요 텍스트, 라벨 |
| 700 (Bold) | 제목, 헤더 |
| 800 (ExtraBold) | 큰 제목, 슬로건 |
| 900 (Black) | 히어로 텍스트, 임팩트 |

### 타이포그래피 처리

- **극단적 크기 대비**: 72pt 헤드라인 vs 11pt 본문
- **자간 조절**: 대문자 헤더에 letter-spacing: 2-4pt
- **라인 하이트**: 본문 1.4-1.6, 제목 1.1-1.2
- **강조 기법**: 볼드 웨이트, 컬러 악센트, 밑줄 (이탤릭 지양)

## 공간 구성 & 레이아웃

### 레이아웃 원칙

- **비대칭**: 불균등 컬럼 (30/70, 40/60, 25/75)
- **오버랩**: 요소 겹침으로 깊이감
- **그리드 브레이킹**: 일부 요소가 그리드를 벗어남
- **네거티브 스페이스**: 여백을 디자인 요소로 활용

### 슬라이드 레이아웃 패턴

**투 컬럼 레이아웃 (권장)**:
```
+---------------------------+
|        헤더 영역           |
+------------+--------------+
|   텍스트    |   비주얼     |
|   불릿      |   차트/이미지|
|   설명      |   테이블     |
+------------+--------------+
```

**사이드바 레이아웃**:
```
+------+--------------------+
| 사이드 |                   |
| 바    |    메인 콘텐츠      |
| 20-30%|                   |
+------+--------------------+
```

**풀 블리드 이미지**:
```
+---------------------------+
|                           |
|   [이미지 배경 전체]         |
|        텍스트 오버레이       |
|                           |
+---------------------------+
```

### 절대 하지 말 것

- ❌ 단일 컬럼에서 텍스트 아래 차트/테이블 수직 배치
- ❌ 콘텐츠 없이 빈 공간만 있는 레이아웃
- ❌ 모든 요소 중앙 정렬
- ❌ 너무 작은 폰트 (최소 9pt)

## 비주얼 디테일

### 기하학적 패턴

- 대각선 섹션 디바이더 (수평 대신)
- 원형/육각형 이미지 프레임
- 모서리 삼각형 악센트
- 겹치는 형태로 깊이감

### 테두리 & 프레임

- 한 면에만 두꺼운 테두리 (3-5pt)
- L자형 테두리 (위+왼쪽 또는 아래+오른쪽)
- 코너 브라켓 (전체 프레임 대신)
- 밑줄 악센트

### 배경 처리

- 단색 블록 (슬라이드 40-60%)
- 분할 배경 (두 컬러)
- 컬러 밴드 (가로/세로)
- **CSS 그라데이션 사용 금지** (PPTX 변환 시 지원 안됨)

## HTML 슬라이드 템플릿

모든 HTML 슬라이드는 다음 구조를 따릅니다:

```html
<!DOCTYPE html>
<html>
<head>
<style>
@import url('https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css');

html { background: #ffffff; }
body {
  width: 720pt;
  height: 405pt;
  margin: 0;
  padding: 0;
  font-family: 'Pretendard', -apple-system, BlinkMacSystemFont, sans-serif;
  /* 배경색 지정 */
}

/* 모든 텍스트는 p, h1-h6 태그로 감싸기 */
p, h1, h2, h3, h4, h5, h6 {
  margin: 0;
}

/* CSS 그라데이션 사용 금지 - 단색만 사용 */
/* 모든 텍스트 요소는 배경색 사용 금지 - div만 배경색 가능 */
</style>
</head>
<body>
  <!-- 슬라이드 콘텐츠 -->
</body>
</html>
```

### HTML → PPTX 변환 제약사항

| 지원 | 미지원 |
|------|--------|
| 단색 배경 | CSS 그라데이션 |
| border, border-radius | box-shadow |
| 텍스트 스타일링 | `<p>` 태그의 배경색 |
| div 배경색 | background-image |
| flexbox 레이아웃 | 복잡한 position |
